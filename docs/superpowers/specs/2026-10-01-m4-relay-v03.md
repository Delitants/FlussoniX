## Wire contract

Implement the observed AVC/AAC M4S Fgop record: one length-prefixed box containing goph child boxes ` utc` (unsigned 32-bit seconds), ` dts` (64-bit float milliseconds), ` num` (unsigned 32-bit sequence), ` dur` (64-bit float milliseconds), and body (a complete M4F segment). The installed 26.04.1 m4stream decoder accepted an independently generated record and preserved these values and body bytes. No vendor code or binary is a runtime dependency. Validate finite nonnegative DTS, positive finite duration, exact field widths, duplicate/absent required fields, bounded payload/sample counts, AVC/AAC tracks and timestamps. Existing 16 MiB record and 32 MiB incremental-buffer limits remain. Unknown opaque records are not executable Erlang terms.

For non-transcoded M4 input, publish the incoming metadata/frame/GOP bytes to the shared wire hub directly, independently of the FFmpeg remux output. M4S→M4S preserves exact received records; M4F→M4F preserves the original segment bytes, timestamp paths and notification lines. Metadata changes reset late-join bootstrap before new media is delivered. Preserve original decode/composition times. M4F input may be exposed as an observed Fgop wrapper over its unchanged segment. Transcoding uses the generated output hub and never claims payload preservation. HLS/TS continue through the supervised FFmpeg packaging worker.

Shared live queues retain at most 256 records AND 16 MiB per queue; slow subscribers receive a lag error and disconnect. Payloads use immutable shared Bytes. Wire bootstrap is capped at 32 MiB; segment cache at 8 entries / 64 MiB. Overflow must not create a late-join bootstrap beginning with an undecodable video inter-frame. No extra worker per viewer. Segment notifications become visible only after their bytes are cached. Duplicate notifications do not refetch/redeliver; malformed paths, oversized bodies and redirects that could disclose native peer credentials fail closed. Each body is fetched under a timeout. Stop/config replacement cancels input and subscriber delivery.

## Native cluster selection

Add source-only `flussonix_transport` = hls|m4s|m4f, default hls for existing installations. Use HTTP(S) private_payload_url to construct hls/hlss, m4s/m4ss or m4f/m4fs source URLs without losing an endpoint path prefix or encoded stream name. Native peer headers authenticate discovery, signal and segment requests, never viewer grants. No implicit fallback to a different transport on failure. Config changes reconcile the worker signature. Public viewer URL/LB routing remains unchanged. Expose upstream protocol in runtime worker stats; surface the source transport choice in the current Cluster UI.
