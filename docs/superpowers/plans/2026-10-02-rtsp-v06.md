# RTSP playback v0.6 implementation plan

Spec: docs/superpowers/specs/2026-10-02-rtsp-v06.md

Execute inline in an owned git worktree. Each task has RED/GREEN evidence, scoped commits and final verification. Existing user authorization governs testing/deployment/publication; no repeated approval menus.

## Global constraints

No production changes or vendor dependencies. Preserve source authority fences and exact-worker cancellation. No per-client transcoding. Bounded queues/control inputs/deadlines. Document partial protocol parity accurately. Secrets stay ignored. Existing tests and UI pass.

### Task 1: Shared RTP packetizer and SDP

Files: src/rtp.rs, src/lib.rs, src/wire.rs, src/m4_ingest.rs, tests/rtp.rs.
Interfaces: Hub config/frame/subscribe produces validated descriptions and track-prefixed immutable packets. Hook normalized frames and packed GOPs once per worker, preserve original native records.
Steps: Write independent packet reconstruction/SDP/bootstrap/overflow tests. Run cargo test --test rtp, Expected: assertions fail with placeholder implementation. Implement H.264/AAC config validation, timestamps, single NAL/FU-A, AAC AU fragmentation, bounded atomic bootstrap/fanout. Run targeted and native relay regressions, Expected: pass. Commit.

### Task 2: Bounded RTSP control parser

Files: src/rtsp/protocol.rs, src/rtsp.rs, tests/rtsp_protocol.rs.
Interfaces: bounded Request/Interleaved events; strict CSeq/content-length/transport parsing; deterministic response writer.
Steps: Write framing/session transport ambiguity tests; run targeted tests, Expected: missing behavior assertion failures. Implement parser and transports. Run targeted tests, Expected: pass. Commit.

### Task 3: Authorized session server and telemetry

Files: src/server/rtsp_access.rs, src/server.rs, src/rtsp.rs, src/main.rs, src/telemetry.rs, tests/rtsp.rs, tests/telemetry.rs.
Interfaces: App RTSP admission resolves existing policy and worker with signature guards. RTSP server owns grant/viewers/packet subscribers. CLI supervises optional listener and cancels all connections. Separate RTSP bytes feed process total telemetry.
Steps: Write socket denial/no-worker, cross-session/path/channel and cancellation tests plus egress regression; run, Expected: assertion failures. Implement admission, serving state machine, sender reports, finite connection/control/write bounds and shutdown. Run targeted tests, Expected: pass. Commit.

### Task 4: Real decode and inbound roundtrip

Files: tests/rtsp.rs, tests/shutdown.rs, relevant regression fixtures.

Correct implementation from causes, preserve source fencing. Run full cargo test --all-targets/fmt/clippy, Expected: all pass. Commit.

### Task 5: Preview documentation and UI accuracy

Files: Cargo.toml/Cargo.lock, web package/lock and traffic labels, README.md, docs/compatibility.md, docs/qualification.md, docs/rtsp-rtp-support.md, capabilities API.

### Task 6: Review, isolated qualification and publication

One fresh whole-branch reviewer; severity by runtime effect; one RED/GREEN fix pass for Critical/Important. Static independent build, own listener port and exact binary FFmpeg RTSP decode on dedicated CDN nodes, preserve running vendor PIDs/listeners. Verify original HTTP cluster regressions. Package independent dependencies/licenses; merge/push, inspect CI, publish v0.6.0-preview, verify remote artifact/checksums, clean owned worktree scratch. Record evidence and limitations.

## Review Focus

Check malicious/truncated AVCC/AAC metadata and access units; timestamp/sequence wrap; bootstrap growth and metadata replacement; source-selected media signature races after callbacks/engine locks; session URI/token/channel confusion; parser fragmentation/pipelining/cancellation safety; grant cancellation while output is backlogged; duplicate PLAY/viewer accounting; packet pacing and sender report clocks; connection deadline and shutdown drain; HTTP-only versus total media telemetry; unsupported codecs do not break existing M4/HLS outputs. Inspect actual FFmpeg behavior rather than declaring protocol completeness.
