# Live worker transport integration

Connect the qualified MPEG-TS worker-output decoder to the shared native hub. This stage replaces the active FLV bridge; CPU HEVC and independent audio encoder controls follow after the worker integration is qualified. No proprietary runtime component is involved.

For non-native-copy workers whose live TS output selects audio/video only, decode existing stdout directly. When Original subtitle tracks are preserved in live TS, use one AV-only MPEG-TS tee channel over an owned loopback socket; keep the subtitle-bearing stdout and HLS outputs intact. Native M4F/M4S copy mode continues to relay original native records and timing, without originating a duplicate native output. Drain stderr separately as diagnostics in every mode. One encoder still feeds the outputs.

Before originating native samples, interleave completed PES events by DTS. A watermark across all declared AV tracks prevents aggregated audio from running ahead of the next video keyframe. On equal DTS publish the video keyframe before audio. Bound the queue to 8192 records and 32 MiB including record overhead; missing initialization, stalled tracks, unsupported codec/layout, malformed transport or native publication failure stop the worker generation with a sanitized reason. Changed configurations and recovery create a fresh Worker/Hub as before. The worker owner cancels and joins tasks, kills/reaps its child and fences obsolete viewers through existing authorization/cancellation rules.

On clean stdout EOF, finalize the decoder and interleave queue before closing. A clean AV-channel EOF also finalizes before closing the generation, even when stdout continues. In preserved-subtitle mode, allow the AV-only reader to finalize within the worker timeout; cancellation/error skips finalization and closes the generation. No late buffered data may be served after worker cancellation. Optional fMP4 copy packaging must not prevent supported TS/native outputs when a copied audio format cannot be represented by that mux/filter profile; unsupported stream combinations must still fail explicitly in native output.

Qualification: owned HEVC with Layer II/III TS publication through both AV-only stdout and subtitle-preserving AV tee; byte/timing/codec reconstruction and independent decode of native remux; queue order/keyframe boundaries, initialization/stall/size bounds, clean final PES and malformed output cancellation/reaping; existing native copy byte equality, AVC/AAC input and CPU transcoding, publication/auth, captions/regional subtitle pass/convert/drop, TLS/RTSP, full Rust/browser, immutable review and exact-head CI. Use only owned fixtures and unused loopback ports, preserve root preview configuration, then publish the qualified source and update the preview with verified ownership.

No new encoder UI/API choice, GPU qualification, production/CDN deployment, long-duration synchronization or capacity claim follows from this integration stage.

Copy publication and peer TS workers map all audio tracks; other non-native inputs retain their existing first-audio selection. fMP4 publication retains its existing AAC ADTS filter profile; copied MPEG audio publication can disable that optional slave while native M4 and TS continue. This stage does not qualify publication fMP4 MPEG/mixed audio. Native copy and inspected peer AAC filters keep their existing codec-aware selection.
