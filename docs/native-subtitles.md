# Native M4F/M4S text subtitles

The native adapters now accept the observed generic `subtitle` codec: a `text` track handler and M4S `subt` frames with content type 4. This is an independent implementation. No official Flussonic component is required by the daemon, build or tests.

## Controls and delivery

Use **Original subtitle tracks → Keep in compatible outputs** on a Stream or Template to retain native text in copy-mode M4F/M4S input and output. **Drop separate tracks** removes the text tracks and their sample payloads. Template inheritance and source discovery use the existing `flussonix_subtitle_tracks` extension. The default remains drop. These controls do not establish exact compatibility with legacy subtitle configuration fields.

Native copy preserves track IDs, codec configuration, opaque track fields, encoded bodies, start/end timing and empty clear samples. M4F segment copy retains the original segment bytes when preservation is selected. M4S frame input keeps its wire records and carries opaque track metadata into generated M4F segments. Filtering compacts sample data and rewrites audio/video chunk offsets while retaining unrelated track fields and sample tables. Audio/video codec changes and explicit M4S declaration changes restart the worker rather than joining incompatible generations. Repeated identical M4S declarations are accepted across quiet segments. Segment inventories may omit silent text tracks; cue/quiet/cue transitions retain the existing AV muxer, continuity counters and clock.

Video/audio packaging continues through the existing native-to-TS bridge. Generic native text is never classified as an audio stream or mapped into TS audio or elementary RTP. A worker requires audio or video; a subtitle-only source is not a qualified worker profile.

## Explicit limits

Generic UTF-8 native text can now be converted into separate WebVTT renditions in both TS and fMP4 HLS. Choose **HLS subtitles → Convert to WebVTT**, **Caption format → Native M4F/M4S · UTF-8 text**, then enter each source track ID, language and display name. The extension row is `{"native_track":7,"language":"en","name":"English"}`. Up to four distinct full-width native IDs are supported; native selections cannot be mixed with broadcast selectors in one stream. Templates and source discovery retain these rows.

Conversion taps the same native input before the independent original-output keep/drop policy. Real source video PTS and output TS/fMP4 clocks align cues. Audio-only sources instead use the first audio track and matching output audio clocks. Video remains the preferred clock whenever present. Native events must arrive in source DTS order; the publication frontier uses decoded DTS to prevent future video PTS from publishing captions prematurely. Empty samples clear a display; explicit end timestamps and earlier clears constrain cue duration. CR/LF normalization, escaping and protected blank rows retain literal text without interpreting markup. XML/bitmap decoding, automatic language selection and GPU conversion remain pending. Copy video and CPU video encoding with original tracks dropped are supported. Audio-only AAC, MPEG Layer II and MP3 inputs support conversion in copy mode, and CPU audio encoding with original tracks dropped. Audio sample PTS offsets must be zero; backward clocks, DTS gaps above ten seconds and late selected text fail conversion explicitly.

Detected sources report **Native text tracks**, **Native text output**, and **Native text in HLS**. HLS status is **Starting**, **Converted**, **Failed**, **Off** or **Not supported** according to the selected path. Invalid selected UTF-8, controls, timing, excessive text/history or discontinuous/late clocks disable conversion for that generation with a visible error and AV-only HLS fallback. Text is bounded to 16 KiB and 64 lines, duration to 120 seconds, and retained history to 4096 cues, 120 seconds and 1 MiB. Delivery uses the existing generation cache and viewer authorization; native passthrough into HLS is still not implemented.

Preserving native text during CPU/GPU transcoding fails with `native_subtitle_transcode_unsupported`. When initial metadata declares text, rejection precedes packager startup. If a previously quiet M4F source first reveals text later, the worker stops with the same error; audio/video may have begun packaging before that discovery. Select drop to transcode audio/video without these tracks. CPU audio transcoding with drop is exercised; GPU native-subtitle retention is not implemented or qualified.

This generic codec must not be treated as a mapping for DVB bitmap or teletext PES. For regional broadcast subtitles, use the [MPEG-TS cluster path](cluster-subtitles.md) and the qualified [CEA, teletext and DVB processing](subtitle-design.md). The literal UTF-8 conversion profile does not establish every reference payload variant, automatic language interpretation, regional native mappings or full Flussonic interoperability.

## Qualification

Owned fixtures contain two independent text tracks, UTF-8 bodies, clear samples and MPEG audio Layer II. M4F, M4S frames and M4S packed GOPs exercise preservation and removal. Four additional M4F/packed-GOP regressions start with quiet text, then alternate cues and silence; they first reproduced AV worker termination and now require all five segments to arrive through one source session. Tests compare encoded bodies, timing, metadata and identifiers, check that removed text is absent from native sample data, and decode real audio/video HLS segments with independent FFmpeg. Existing AAC elementary RTP remains usable with native text declared.

HTTP delivery tests require viewer authorization before a source pull, verify token checks on cached native assets and revoke delivery when a stream is disabled. Source requests retain their own query credentials; native peer keys are origin scoped. Configured `m4fs://` and `m4ss://` inputs support an optional `flussonix_tls_ca` absolute PEM path, shared with RTSPS. The custom bundle replaces public roots and must be readable on each receiving host; leave the field empty for public roots. Certificate chains and source identities are always verified. Secure native control and segment redirects stay within the configured HTTPS origin (up to three requests); peer-authenticated pulls reject all redirects. This does not configure cluster discovery or management API trust.

Owned private-CA tests pull HEVC, Layer II audio and two UTF-8 text tracks over M4FS/M4SS, then deliver protected TS/fMP4 WebVTT and native output over HTTPS. They verify early clear timing, rendition isolation, exact retained M4F cue/clear segment bytes, cached token denial and disable revocation. Quiet M4F late-join GOPs legitimately omit silent text tracks. Untrusted/wrong CA, wrong source identity and expired certificates fail before application data; both control and segment redirects reject plaintext and foreign origins. Same-origin HTTPS redirects work without peer credentials and are denied when peer authentication is used.

Read-only, disposable library checks against the locally installed reference version 26.04.1 accepted independently generated metadata, text/clear frames and M4F cue timing. Reference re-encodings were also decoded by FlussoniX. Reference inputs/outputs and inspection artifacts are private research records, not shipped fixtures or dependencies. CI uses only owned fixtures and verifies that `/opt/flussonic` is absent. These checks do not qualify production concurrency, migration servers or every vendor payload variant.

Native HLS qualification uses the existing owned HEVC fixture and two UTF-8 text tracks, including ID 4294967295. M4S frames, packed GOPs and initially quiet/sparse M4F segments exercise both HLS variants, early clear timing, Unicode, blank rows and independent native filtering. Independent FFmpeg decodes copy/CPU AV output. Browser HLS.js playback exercises selectable native text and verifies clear intervals with CPU H.264 output. Auth checks deny pre-worker requests, protect cached VTT files, propagate viewer tokens, and reject old-generation assets and disabled streams. Unit checks exercise malformed payloads, timing, history bounds and clock errors. No reference module is used by these tests.

Owned audio-only fixtures exercise M4S frames, packed GOPs and sparse M4F delivery, AAC/Layer II/MP3, copy and CPU encoding, independent original track keep/drop, two selected text IDs and early clears. Malformed selected text falls back to audio delivery. Tests verify one source session and independently decode both HLS variants; browser playback exercises selectable UTF-8 text over real audio. Subtitle-only conversion remains unsupported.
