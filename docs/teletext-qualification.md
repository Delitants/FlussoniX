# Teletext qualification

Streams and Templates can convert selected DVB teletext pages100..899 to selectable plain-text WebVTT alongside CEA-608/708. Use HLS subtitles → Convert, choose Teletext, page, language and display name. Four combined distinct renditions are supported. API rows use `{"teletext_page":888,"language":"de","name":"German"}`; existing channel/service rows and URLs are unchanged. New assets use `ttx888.m3u8` and generation-owned `ttx888_g…_….vtt` in both TS and fMP4 HLS.

The independently implemented Rust parser reads copied video and subtitle PES from the same FFmpeg input session before CPU encoding. It requires H.264/HEVC video clock extraction and an announced DVB teletext subtitle/hearing-impaired page descriptor. It selects at most four PIDs, checks PSI CRC/lengths, PES timestamps/framing and transport continuity, and rejects ambiguous duplicate page announcements across PIDs. PMT ownership changes discard affected queued PES and clear stale display. Stats report each configured page's PID/availability and decoder degradation; an unavailable page does not block AV.

The Level1 profile handles serial/parallel magazine association,24×40 rows, header/subpage/erase/inhibit changes, boxed text, conceal and mosaic suppression. Latin G0 uses the default Western/Central Europe national subsets: English, German, Swedish/Finnish/Hungarian, Italian, French, Portuguese/Spanish and Czech/Slovak. Hamming8/4 corrects single-bit errors; uncorrectable address/header errors clear affected PID display, and bad character parity becomes a replacement character with degraded status. Repeated unchanged pages produce no new cue. A page completes at a terminating header or after100ms of source-clock inactivity and keeps its header timestamp. Blank/erase pages close cues; silence does not expire a displayed subtitle by wall clock.

Limits: four combined selections, four selected PIDs,4096-byte PSI,65541-byte PES,64 queued PES events/256KiB, fixed page rows, and existing4096-cue/120-second HLS retention and rendition byte limits. Safe video DTS frontier orders PES events before page timeout/manifest readiness; timestamp wrap, B-frame ordering, packet gaps, generation changes and queue recovery have literal tests. Malformed teletext clears its pages independently of608/708; AV continues. Existing HLS auth, HTTPS endpoint routing, token propagation and stream-policy revocation apply to every resource.

Owned16-second H.264/AAC video has German page888 and French889 on separate teletext PIDs, plus unrelated DVB subtitle PES. At1.16s they display GRÜSSE and français; at3.00s they clear. At4.12s both display `LIVE <&>` and at6.00s clear, followed by ten silent seconds. Source muxing uses zero mux delay and frequent PCR so teletext PES timing falls within the demuxer's PCR tolerance. Copy and CPU tests verify both HLS variants, source cue boundaries, page isolation, escaped markup, empty segments, original descriptor/payload preservation on shared MPEG-TS, and token revocation. Declared-but-absent packets and an unannounced selected page keep both AV variants progressing in copy and CPU modes.

Independent private qualification used the host FFmpeg/libzvbi decoder over this real owned media. It produced both expected Unicode words at1.16s and the second phrase at4.12s. The probe sets a fixed display duration to export text; it does not qualify native erase durations through that option. Native erase boundaries are verified with literal packet timing and actual WebVTT delivery. No upstream decoder source or oracle is bundled as a product/build/test dependency. Character-set and carriage references are [ETSI EN300706](https://www.etsi.org/deliver/etsi_en/300700_300799/300706/01.02.01_60/en_300706v010201p.pdf) and [EN300472](https://www.etsi.org/deliver/etsi_en/300400_300499/300472/01.02.02_60/en_300472v010202p.pdf).

Exact typography, colors, layout, flashing, enhanced X/26/X/28/M/29 packets, alternate/Cyrillic/Greek/Arabic/Hebrew sets and bitmap OCR are outside this profile. Enhanced or alternate-set signaling clears affected conversion and reports degradation, even when some base text might be readable. First-program, single-section PSI is qualified; automatic page detection/configuration, GPU conversion, real HEVC browser playback and regional source-to-CDN subtitle relay remain unqualified. Original pass-through/filter policies stay independent; this is not full Flussonic compatibility or migration readiness.
